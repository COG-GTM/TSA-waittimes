US Checkpoint Wait Picture

Public API v1

Read-only airport security wait times and source health for applications and websites.

Endpoints

GET /api/v1/airports

List airports with live checkpoint data.

curl https://waitpicture.com/api/v1/airports
{
  "generated_at": "2025-01-15T12:00:00+00:00",
  "data_notice": "Wait times are aggregated from officially published public data sources; ...",
  "airports": [{"iata": "DEN", "standard_wait_seconds": 900, "precheck_wait_seconds": 300, "stale": false, "source_url": "..."}]
}

GET /api/v1/airport/{IATA}

Return airport metadata, checkpoint observations, FAA events, alerts, and travel period data.

curl https://waitpicture.com/api/v1/airport/DEN
{
  "airport": {"iata": "DEN", "name": "Denver International Airport", "...": "..."},
  "checkpoints": [{"name": "North", "lane_type": "standard", "wait_seconds": 900, "is_open": true, "...": "..."}],
  "faa_events": [], "weather_alerts": [], "generated_at": "2025-01-15T12:00:00+00:00",
  "data_notice": "Wait times are aggregated from officially published public data sources; ..."
}

GET /api/v1/status

Return source health and the current observation count.

curl https://waitpicture.com/api/v1/status
{
  "status": "ok",
  "observations": 1234,
  "sources": [{"source": "denver", "healthy": true, "...": "..."}],
  "data_notice": "Wait times are aggregated from officially published public data sources; ..."
}

Embeddable widget

Embed a compact airport summary with an iframe:

<iframe src="https://waitpicture.com/embed/DEN" width="320" height="180" style="border:0" title="DEN security wait times"></iframe>

The widget is self-contained and uses no external JavaScript or CSS.

Usage and attribution

Sources poll every ~120 seconds, and responses may be cached for a couple of minutes.

Requests are limited to 60 requests/min per IP. Exceeding the limit returns 429 with a Retry-After header.

CORS permits GET requests from any origin on /api/v1/* only. Other routes do not enable CORS.

Data notice: Each response includes a data_notice field. Data is aggregated from officially published public sources; consumers must retain the attribution and source_url fields when displaying data.
